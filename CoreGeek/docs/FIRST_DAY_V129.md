# v1.2.9 首日三次任务、三券与新防线

2026-10-12。当前首日流程：三火箭与新17墙防线并行建设，开拓者固定尝试任务1、任务2、任务1；全部三次尝试结束后按真实成功次数冻结0～3张BOSS券。用券继续等待工人侦察和当前普通单位视野。完整布局见[己方17墙与临时入口](HOME_LAYOUT_V129.md)，机器人目标顺序见[攻城策略](ROBOT_SIEGE_V129.md)，敌阵侦察机制见[布局侦察](LAYOUT_SCOUTING.md)。

## 任务顺序与冷却

`TASK_SEQUENCE=(1,2,1)` 只控制第一天。任务编号读取官方`taskType`后缀；任务2仍使用`Turn.task_cells()`的两个有效格，不把任务点2误缩成一个格。第三次可以使用任务1的新题目，不要求题目文本不同。

每次任务结束后刷新30回合，成功、失败、超时均按官方状态处理。第二次任务用时未覆盖完整冷却时，开拓者在任务1合法邻格等待`isValid=True`且`coldDownRounds==0`；等待不是一次新尝试，不能提前购券。走向任务点的时间可以与冷却并行，估算采用`max(路程,剩余冷却)`。每次领取仍预留官方任务时限、回防路程与`return_margin`。

任务仍然活跃时由原`TaskService/SelfEvolveController`处理。领取失败不计数；已成功接取而题目尚未出现时等待，不立即当成失败，延后出现也保持已确认的点位和领取回合，不在相邻两点间重新猜身份；未出现的题目超过该点时限才记录结束。真实活跃题目消失、明确结算、超时、离开或死亡引起的终止均按同一次尝试归档。若第三次任务不可领取或剩余白天不足，返回防守，不虚构第三次结束来买券；首日夜间采购窗口和原夜间经济限制保持。

第二天及以后继续原有每日两个任务点调度，本次只改变首日序列。

## 一次尝试一个身份

旧`task_points_attempted/finished/succeeded`是按`(day,x,y)`去重的集合，两次任务1会合并，不能用于三次计数。现在保留这些集合用于兼容展示，实际计数使用内部事件账本：

```text
GameMemory.task_attempts[(day, accept_round, x, y)]
    kind, point, origin, finished, succeeded
    finished_round, reason（结束后写入）
```

`accept_round`是实际领取指令所在回合；观测里的匹配成功反馈或实际任务phase确认后才注册。`task_active_attempt`指向当前尝试，`TaskAgentMemory.attempt_key`把控制器执行和原尝试绑定。题目文本一样也用新的领取回合重置执行状态，旧提交反馈不能跨运行记给新题。

`finish_attempt()`是幂等的，同一次结束、成功反馈和后续phase消失不会重复加次数。成功仍需要实际`submitAnswer`、匹配合法反馈、无相关判错、金币或积分奖励证据；失败可以结束但不算成功。没有本回合反馈或跳轮时不拿旧提交作新成功。

中途恢复只能从当前真实活跃题目及可确定的邻近点登记当前一次，不能从金币推断已经完成前两次。账本里的`origin='isolated_fixture'`只存在于库存隔离单测，不能当作正式30回合冷却链路证据；真实HTTP回归独立走冷却与任务反馈。

## 冻结数量与库存确认

| 首日真实成功次数 | 第三次尝试结束后购券目标 |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |

`BossRaid`的潜在预算、持券账本、实际购得数、部署数均支持上限3。金币变多不增加冻结数量；金币只够两张时也不能把三成功目标自动降成两张。三张可以一次`buy(num=3)`，三次`use`分开三个回合、使用不同合法出生点；选第三点时把前两只待生成位置作为路径障碍，仍受背包、实际金币、每日10次上限与回防时间约束。

三次结束前潜在BOSS预算为三张的当前价格，仍保留缺失三炮的25金币/座。武器升级采购在开拓者实际购券尝试后解锁；不必等待三次召唤结束。零成功或明确不可行时释放经济阶段；成功买到的实物券经背包和匹配反馈确认后才使用。缺反馈、异常部分库存和失败use的防重购/回滚机制保留。

每次`use`继续要求已侦察真实布局、活工人实际到位和当前普通共享视野；BOSS自身不提供视野。第三只同样不能盲目召唤，不能复制前两只的出生格。若后续用券窗口过期，保留未用券，已部署BOSS仍有原侦察支持。

## 建设与工人通行

默认布局从12墙改为用户两张水平镜像的17墙，炮和中间操炮位原坐标保留。新增侧后墙纳入原最终2级目标，正面6墙升级顺序保持，基地不升级。

新图完整封口后，炮台会隔开后侧开口与内侧维修通路。因此白天由一块上后墙作受控临时入口，夜前从内侧封回17墙；工人在次晨实际拆墙后继续外出采矿、售矿和补给。拆墙不退石、不保留等级，详细费用与2级门券预备见布局文档。

门负责人的封口石1既不能卖掉，也不计入普通16墙的可用石头，防止远处负责人拿最后一块石头抢近处施工者的墙。初次收集目标总量为16普通墙加1封口石；另一工人可以独立施工。双工回防先清入口一格通道，捣乱鬼普通白天避开唯一维修横道，临夜在缺口附近待命，保留肉身接力。
