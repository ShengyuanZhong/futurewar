# 火箭的半区分配与积分/血量选点

v1.1.2，2026-10-09。依据用户策略要求及 `32_docs/任务书.md` §4.5.1、§4.5.4、§4.7.2，所有等级火箭统一要求落点中心有活机器人，按九宫格内逐个机器人的击杀分/当前HP之和最大选点。三级继续两发己区、一发敌区。中心伤害20、周围八格10，多弹重复落点伤害叠加，发射后3回合冷却由官方观测控制。

## 选点公式

对每个合法中心计算：

```text
S(中心) = Σ[机器人类型击杀分 / 本轮观测当前HP]
参与求和：HP > 0，且到中心的切比雪夫距离 ≤ 1，即中心及周围八格。
候选中心：本轮观测活机器人的坐标，在地图内、非炮台本格、符合当前射程。
```

己区与敌区使用相同公式。半区只约束中心的候选池，九宫格跨过边界时仍计入所有覆盖的活机器人。空中心即使覆盖更多积分/血量，也不参与候选；HP≤0既不贡献分值，也不能充当中心，不会出现除零。

| 类型 | 文档初始HP | 击杀分 | 满血时分/HP |
|---|---:|---:|---:|
| `smallRobot` | 40 | 1 | 1/40 = 0.025 |
| `middleRobot` | 60 | 2 | 1/30 ≈ 0.033333 |
| `largeRobot` | 500 | 4 | 1/125 = 0.008 |
| `bossRobot` | 800 | 10 | 1/80 = 0.0125 |

分母使用报文中的**当前剩余HP**，不使用上述初始HP或本地预测HP。例如BOSS只剩10HP时为1，优先级高于单个满血小型机器人。公式是各机器人的比值之和，不是总积分/总HP；对多个机器人求和后，最大化Σ(分/HP)与最小化Σ(HP/分)并不等价，因此直接实现用户首选公式。

使用标准库 `Fraction` 精确求和，避免浮点误差影响并列中心。每台炮每次选择只聚合一遍，每个机器人向九个可能中心贡献其比值，聚合次数为9N；随后在活机器人坐标中查最大值。同值先选距炮台较近的中心，再按固定坐标顺序选择，结果不依赖机器人列表顺序。

同次攻击使用同一份观测HP计算分值，同一半区的多枚导弹可重复最优中心。临时预测HP仍按中心20/邻格10依次扣减，用于选择可操作的炮台和预计有效伤害，不改变同轮的分值、活机器人候选或2+1配额。最终击杀积分由官方判题器结算。

## 分配与合法性

按本轮观测HP>0且中心合法可达的机器人分组，不按预测HP或 `targetTeam` 决定半区：

| 观测情况 | 三级火箭安排 |
|---|---|
| 己区、敌区都有合法中心 | 前两枚重复己区最大S的中心，最后一枚为敌区最大S的中心 |
| 敌区无合法中心 | 三枚全部用于己区最大S的中心 |
| 己区无合法中心，敌区有 | 三枚重复敌区最大S的中心 |
| 全场没有合法活机器人中心 | 不安排攻击 |

一级/二级火箭在原有射程内的全部活机器人中心中按同一公式选择，分别输出1/2枚。中心占用约束也适用于它们：不能通过射程内的空中心溅射射程外机器人。其它炮型继续使用原伤害/威胁选择流程。

半区与捣乱鬼共享左下→右上对角线 `(0,0)` 到 `(width-1,height-1)`。侧值 `y*(width-1)-x*(height-1)` 的正负区分上下侧，己方2×2基地中心所在侧是己区，不按challenger/defender写死，支持换边。基地缺失时由可见敌基地反推，再退回炮台所在侧；仍无法判定时在全部合法中心中按S选点。边界机器人归入防守池，敌区中心要求严格位于对侧。

落点仍检查地图内、非炮台本格和当前合法射程；攻击仍需夜晚、冷却为0、操控者相邻且本轮未行动。正常三级火箭按文档为全图，异常的观测射程仍受合法性约束。`targetPos` 前两项是己区、第三项是敌区；无敌区中心时三项都是己区。开拓者每轮仍只操作一座炮。

## 函数与数据流

| 位置/函数 | 参数与作用 |
|---|---|
| `src/agent/map_regions.py` `diagonal_side(pos,width,height)` | 坐标→1/-1/0，与捣乱鬼共用 |
| 同上 `base_side(turn)` | 按2×2基地中心判断己区，可由敌基地反推 |
| `combat.py` `ROBOT_POINTS` | 小1/中2/大4/BOSS10的固定击杀分 |
| 同上 `_rocket_efficiency_scores(robots,deadline)` | 机器人列表、绝对软截止时间；返回中心→精确Σ(分/当前HP)，超时返回None |
| 同上 `_occupied_rocket_target(turn,tower,centres,scores)` | 观测、炮台、对应半区候选机器人、预聚合分值；过滤非法中心并返回最大S的Pos，无候选返回None |
| 同上 `choose_targets(turn,tower,expected_health,deadline)` | 返回符合等级/配额的完整落点列表；仅完整方案生成后才更新调用方的预测HP字典 |
| 同上 `_apply_damage(health,damage)` | 机器人ID→临时预测HP、机器人ID→预计伤害；逐发扣减，不写回观测 |
| `Strategy.operate_weapons(role)` | 从就绪、可操控炮台中选择一座；输出以武器ID为键，controllerId为开拓者 |

工人、捣乱鬼和任务模块继续使用原策略。没有增加HTTP字段、路由、配置或外部依赖。
