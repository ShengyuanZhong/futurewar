# 三级火箭的防守与敌区取分策略

v1.1.1，2026-10-09。依据用户需求及 `32_docs/任务书.md` §4.5.1、§4.5.4、§4.7.2，三级火箭每次仍发送3个落点；中心伤害20、周围八格10，多弹可以重复落点并叠加，发射后3回合冷却由官方观测控制。

## 分配与敌区落点

按本轮观测HP>0的机器人分组，不按预测血量或 `targetTeam` 决定半区：

| 观测情况 | 三级火箭安排 |
|---|---|
| 己区、敌区都存在机器人 | 前两枚落点在己区，最后一枚在敌区 |
| 敌区无活机器人 | 三枚全部用于己区 |
| 己区无活机器人，敌区有 | 空余两枚转给敌区，三枚重复敌区最高总分中心，避免空射 |
| 全场没有活机器人 | 不安排攻击 |

己区两枚沿用防守威胁和预计伤害排序，候选包含己区机器人及其相邻空中心，落点本身限定己区。每枚的估计伤害依次扣入临时预测血量；即使临时预测已经归零，观测仍存活的己区机器人也不会导致本次2+1分配变化。重复落点用于满足合法的目标数量要求。

敌区候选**仅为敌区活机器人的坐标**，不允许空中心。在每个候选的3×3九宫格内，对所有观测存活机器人加总完整击杀分：小型1、中型2、大型4、BOSS10。跨过半区边界的溅射机器人也计入九宫格总分。按总分最高选点；同分按离炮台更近、再坐标确定顺序。

这不是预计本发能拿到的积分，也不乘伤害比例、不以机器人数、HP或BOSS优先规则替代总分。比如8个小机器人总分8，单个BOSS总分10；6个中型机器人总分12，优先于单个BOSS。空中心即使覆盖分数更高，也不会成为敌区落点。最终得分仍由官方判题器结算。

## 半区与合法性

与捣乱鬼共享文档中的左下→右上对角线 `(0,0)` 到 `(width-1,height-1)`。侧值 `y*(width-1)-x*(height-1)` 的正负区分上下侧，己方基地中心所在侧是己区，不按challenger/defender写死，支持换边。

基地缺失时可由可见敌基地取反侧，再退回炮台所在侧推断；仍无法判定时沿用原伤害选择。边界机器人归入防守池，敌区候选要求严格位于对侧；捣乱鬼对边界矿的跳过规则保持原状。角色、武器位置和机器人数据使用实际输入，原件不改写。

全部落点仍检查地图内、非炮台本格和当前合法射程，攻击仍需夜晚、冷却为0、操控者相邻且本轮未行动。如果观测中的射程使所有敌区中心不可达，则使用合法己区目标或不攻击，不输出非法坐标。射程正常的三级火箭按文档为全图。

## 函数与数据流

| 位置/函数 | 参数与作用 |
|---|---|
| `src/agent/map_regions.py` `diagonal_side(pos,width,height)` | 坐标→1/-1/0，与捣乱鬼共用 |
| 同上 `base_side(turn)` | 按2×2基地中心判断己区，可由敌基地反推 |
| `combat.py` `ROBOT_POINTS` | 四类机器人固定击杀分，来自任务书 |
| 同上 `_enemy_score_target(turn,tower,enemies,robots,deadline)` | 敌区中心候选、所有活机器人；用九宫格聚合总分选点 |
| 同上 `_greedy_targets(turn,tower,robots,candidates,count,health,deadline,fill_zero=False)` | 给定目标池/候选/枚数，在临时health上逐发做威胁/伤害排序；fill_zero保持观测分配，避免预测归零使配额消失 |
| 同上 `choose_targets(turn,tower,expected_health,deadline)` | 返回合法完整落点列表；只有完整3枚方案生成后才提交临时预测血量 |
| `Strategy.operate_weapons(role)` | 仍从就绪、可操控炮台中选择一座；输出以武器ID为键，controllerId为开拓者 |

一级/二级火箭及其它炮型保留原目标选择，工人、捣乱鬼、任务策略未扩大改动。共享半区函数的迁移由捣乱鬼原回归覆盖。没有增加HTTP字段、路由、配置或外部依赖。

`targetPos`的前两项表示防守落点，第三项表示敌区落点；敌区没有活机器人时三项均为己区，合法重复坐标正常。开拓者仍每轮只操控一座武器，不通过增加指令规避冷却。

## 本地验证

`tests/test_rocket_sectors.py`覆盖双方位置/标签、2+1与三发防守、单侧无机器人、BOSS/小机器人与中型群的分数比较、空中心排除、跨界九宫格、预测血量、targetTeam冲突、超时不提交部分方案、低等级射程与数量、真实Strategy输出和冷却。首批13项在旧版有7项失败。压力工具独立按机器人坐标和原始类型计算九宫格总分、核对3级火箭分配，不复用选点实现。

完整结果见[v1.1.1验证报告](../../reports/VALIDATION-v1.1.1.md)。本地输入与预测伤害不代表真实比赛得分，不宣称共享击杀分或胜率已在本版实测。
