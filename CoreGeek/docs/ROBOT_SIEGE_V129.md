# v1.2.9：BOSS 先清炮手，再从原位攻击基地

本次仅更新第一天夜晚的可控 BOSS 攻击策略。协议与合法性仍依据 `32_docs/任务书.md` §4.5.4、§4.7.3 和 `32_docs/接口文档.md` §2.2：机器人可攻击敌方英雄、基地、建筑；切比雪夫射程为 3；一回合只能移动或攻击。机器人没有视野，攻击目标必须来自本回合真实观测；真实见过的静态建筑可用于保守规划，不能代替当前可见目标。

## 决策顺序

1. 继续优先攻击真实可见、炮台周围一格内的敌方工人或开拓者。每回合重新确认存活与血量，角色回血不表示目标已被击杀。保留已有有限追击预算、真实布局确定后的单墙突破、长绕路回退与失败缓存。
2. 转攻基地时，检查敌方基地 2×2 的全部格子。若本回合原位至少有一个可射格子，则保留原位，避免为了旧射击站位再走路。
3. 在上述原位可以射到基地的前提下，如果没有任何已知存活敌方炮台，则检查基地 footprint 周围一格内的真实可见工人或开拓者：原位射程内、弹道清晰且未在失败缓存中的角色先被攻击。没有这样的角色时，攻击基地。不会为了此类次要角色移动或绕路。
4. 如果没有可直接攻击的基地格子，但原位射程内的基地弹道被敌方炮台阻挡，则攻击该弹道上当前真实可见、可直接射击的第一座炮台；炮台前面有城墙时先攻击第一堵墙。存在另一条清晰基地弹道时直接打基地，不拆挡住其他方向的炮台。
5. 没有上述原位动作时，继续已有的基地射击站位寻路和必要城墙突破。

“没有炮台”同时考虑当前观测和 `GameMemory.enemy_structures` 中真实见过的存活炮台。炮台离开普通单位视野后，不能因请求不再列出它就认定被摧毁。普通单位视野覆盖其位置、确实观测到空格或死亡后才移除记忆。机器人自身不参与视野覆盖计算。

## 函数与状态

源码：`CoreGeek/src/agent/robot_raider.py`。

| 函数 | 参数与返回值 | 作用 |
| --- | --- | --- |
| `RobotRaider.attack_base(robot, route, fallback=None)` | `robot` 为本方可控机器人；`route` 为当前回合含动态占位和记忆建筑的 `Routes`；`fallback` 保留炮手不可达、超出预算等原因；返回动作是否成功加入 `ActionPlan` | 清理旧炮手追踪状态，检查原位基地落点、无炮台后的近基地角色、挡路炮台，最后接入原有基地追击 |
| `RobotRaider.base_weapon_obstruction(robot, points)` | `points` 为真实敌方基地 footprint；返回真实可见首个敌炮台/城墙 `Unit`，或 `None` | 只检查射程内的原位基地弹道；必须确认炮台位于该射线，且实际首个障碍可直接攻击；不将记忆中的隐藏炮台作为攻击目标 |
| `RobotRaider.clear_shot(robot, target, audit=None)` | `target` 为目标坐标；返回是否有真实敌目标、射程和墙体合法，并满足保守建筑弹道检查 | 仍保留 45° 射线只受对角线格遮挡的用户确认规则 |
| `RobotRaider.issue(...)` | 一个 `attack` 或 `move` 动作；返回 `ActionPlan` 是否接受 | 更新当前任务阶段和反馈缓存，不组合移动攻击 |

`robot_raids` 新增动作阶段 `weapon` 和 `base_nearby`；挡路城墙沿用 `breach`，`pursuit_kind='base'`。`nearby_role_id` 仅用于记载本次次要角色攻击。每回合目标仍重新读取真实观测，不持续攻击隐藏或已死角色。

`robot_diagnostic` 增加 `direct_base_cells`、`base_nearby_allowed`、`base_nearby_candidates`、`siege_obstruction`、`secondary_reason`，用于区分“保留原位攻基地”“原位清扫近基地角色”“清除基地弹道障碍”。`weapon_on_base_ray` 表示攻击了挡路炮台或它前面的第一堵墙；`stationary_base_neighbour` 表示无已知存活炮台时攻击了原位可射的近基地角色。

## 本地验证与限制

`CoreGeek/tests/test_siege_weapons.py` 使用人工可核验观测覆盖原位基地射击、三类炮台清障、首墙遮挡、隐藏炮台记忆、实际炮台消失、角色回血、次要角色不绕路、炮手优先和失败缓存。观察输入是合成场景，不是官方比赛或机器人自动提供的视野。

炮台与角色建筑内部弹道继续使用已有保守规划判定；本次没有改写任务书或官方判题行为，也没有把本地通过率视为官方对局效果。真实对局仍需核对动作回执与目标血量变化。
