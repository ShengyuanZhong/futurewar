# v0.4.3 任务模块整合与本地验证

本版在用户确认的 v0.4 策略基准上，将 `temp/task_controller(1).py`、`temp/task_prompt(2).py` 接入正式任务链路，保留原件。新版控制器增加提交奖励基线、临期命令预算和占位答案拦截；新版提示词增加 `unknown-api` 与 `engineering-fix` 分类经验。适配时沿用本项目对命令业务错误、截断前 JSON 结构和失败教训的识别。开拓者继续按两个任务点分别调度，失败或成功后可前往当天尚未尝试的另一任务点。

`TaskService` 从 `teamOur.totalScore` 和 `goldNum` 构造控制器状态。提交后的 `lastRoundRoleActionResults=true` 只表示动作合法；控制器只有检测到金币或分数增长才将该次任务经验归档为成功。该判据来自新模块，不能单独证明官方给出的通过率；同回合其它收入也可能使金币增加。任务结束后 `phaseTask` 已清空时，本地动作校验不允许补交答案。
