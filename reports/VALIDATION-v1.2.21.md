# v1.2.21 集中破墙与基地集火验证

2026-10-13。基于 `86c7d3b` 的 v1.2.20，按用户两张阵型图更新第一天召唤和第一夜 BOSS 协作。实现、函数参数与共享状态见[开发文档](../CoreGeek/docs/COORDINATED_WALL_ASSAULT_V1221.md)。本轮没有新官方对局，仅验证第一天。

## 实现与检查

- 使用真实基地、全局可见墙体、已确认炮位及当前可见人员判断墙保护。静态八向可达搜索保留开放入口；角色临时占门、纯武器挡线、失视、超距不等于受墙保护。45°射线沿用对角线遮挡规则。
- 受保护场景在不同侧选择同一堵墙和多个合法出生点，结合实际浪潮位置降低暴露风险。逐张用券共享墙目标，排除已预约、失败及不合法位置。
- 夜间集中攻击共同墙，确认实际墙死亡或不存在后推进基地。前排保留基地射线并腾位，后排寻找可达射击格；全队实际进入基地射程后集中攻击，不追人员。移动和攻击分轮进行。
- 最佳操炮位已由本方 BOSS 实际占住，且全部存活 BOSS 当前能直射基地时，基地集火优先于敌方人员。未占位、部分超距、墙挡线、眩晕等情况不能用预测站位触发。
- 保留三任务、工人采购、炮位记忆、直墙施工等基线。旧封闭阵型测试迁移到共同破墙策略，保留实际射程、遮挡、材料、视野、同时占用和反馈断言。

## 两张图的完整流程结果

下表“己方基地”与 HTTP 报告的 `case` 对应；敌方基地在另一侧，因此突破方向也随之反转。所有四组均在 R37 批买三券，R38～40 分别使用；R71～79 三只 BOSS 向同一堵墙发出 27 次攻击，R80 才观察到破口。R82 首次攻基地，R85 首次三只同时攻基地，R96 最后结算后基地血量为零。全过程敌操炮手保持 500HP，未被攻击。

局部输入使用 1000HP 墙、1500HP 一级基地、500HP 敌角色和每只 BOSS 每轮 40 伤害。攻击按同轮共同结算，允许过量伤害；每组共有 40 次基地攻击。没有敌方回击，不能把 R96 当成官方比赛击破时间。初始己方三炮、17 墙已建，任务奖励及敌布局为隔离输入，本次 HTTP 不验证从出生造炮建墙的耗时。

既有占位 HTTP 并非每一轮都满足全队直射条件：R78 共同位仍有实际敌工人时按原策略攻击，R82 某一 BOSS 射线受真实墙阻挡时允许拆墙；满足条件后的全队攻基地由独立检查和新增单元场景验证，不能把条件扩大为无视射程或遮挡。
