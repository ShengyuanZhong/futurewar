- 使用实录基地(30,10)、工人(30,8)/(31,8)与矿点坐标，不存在整圈未建墙产生的虚拟封路；多种合理开拓者出生格R1发移动指令。原日志缺少其真实初始坐标，不能声称完整恢复官方轨迹。

## 复现

在项目根目录运行，每条命令单独执行：

```powershell
python CoreGeek/tools/validate_first_day.py --output reports/validation-v1.2.10.json
python CoreGeek/tools/smoke_first_day_flow.py --output reports/http-first-day-flow-v1.2.10.json
python CoreGeek/tools/smoke_scout_flow.py --output reports/http-scout-layout-v1.2.10.json
python CoreGeek/tools/smoke_gap_flow.py --output reports/http-gap-boss-flow-v1.2.10.json
```

`validate_first_day.py` 显式选择首日用例，不调用全目录发现或多日压力生成器；输出已选用例、排除用例、规则/源码/原始日志SHA256。已验证的是源码，不是历史`dist/`wheel。
