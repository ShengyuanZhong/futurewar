# v1.1.0 捣乱鬼策略本地验证

2026-10-09。以 v1.0.2（Git `b7f1add`）为基础，依据用户指令及 `32_docs/` v2.0 的矿区半区、imp角色、destroy连续4回合和复活规则，加入独立的捣乱鬼策略。模块、状态、参数与边界见[开发说明](../CoreGeek/docs/IMP_STRATEGY.md)。官方原件没有改写，生产源码不依赖参考文件目录。

| 本地检查 | 结果 |
|---|---|
| 完整回归 | 250项通过，0失败、0错误；新增14项imp回归 |
| 合成观测 | 80份通过，双阵营；40份带imp、40份保留三角色；0–150机器人夜间压力 |
| 合成imp输出 | 20条move、20条destroy，0等待；独立检查角色权限、矿点/距离、敌半区与移动占用/目标冲突 |
| 原样初赛HTTP | 真实进程健康检查通过，POST返回200，约48ms、3条动作 |
| 初赛/复赛样例离线回放 | 各1份完成；复赛原样request.txt新增ID10014的move至(22,25) |

14项新用例覆盖上下半区/双方标签、己方矿排除、跨黄昏四次连续破坏、矿点消失后重选、失败反馈不导致本地提前结束、夜间低血与威胁范围、实际机器人障碍、死亡/次日第1回合恢复、漏收死亡的复活位移重规划、基地缺失后的半区记忆、动作参数/权限/单轮互斥、活跃任务并行、日志与会话/新局隔离。首批10项用例在旧版中有9项失败，表现为缺少控制动作/状态或拒绝destroy；原工人经济、建造、升级、夜修、开拓者战斗与任务模块的回归继续通过。

机器记录：[回归/压力/源码及复赛原件哈希](validation-v1.1.0.json)、[初赛HTTP](http-smoke-v1.1.0.json)、[初赛响应](sample-response-v1.1.0.json)、[复赛响应](round32-response-v1.1.0.json)。峰值输入决策约414ms，是本地机器上的合成输入结果，不是官方性能或胜率。

连续4次的测试通过动作反馈夹具检查逐轮指令；未调用官方判题器，不宣称已实测矿石销毁、10轮刷新抑制或真实复活结算。线上矿点是否消失、角色是否复活仍由官方观测决定。本次只接入imp的move/destroy，其它v2.0变更状态见[复赛规则索引](../CoreGeek/docs/ROUND_OF_32_RULES.md)。
