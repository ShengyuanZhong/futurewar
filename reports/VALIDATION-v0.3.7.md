# 本地验证报告：0.3.7 工人独立任务与城墙掩护

日期：2026-09-22。基于0.3.6增加逐工人任务/目的格、协作侧移让路、城墙掩护、上下分区值守及动态修复包库存；原升级顺序与基地不升级保持。涉及R02/R03/R05/R06，属于策略与工程实现变更，没有修改官方原文或动作校验。

## 结果

| 项目 | 实际结果 |
|---|---|
| 完整回归 | 169项通过，0失败、0错误，11.855秒；新增14项工人协作案例 |
| 独立任务 | 两工人选择不同可用矿点和目的格，任务按ID保存；死亡和过期记录清理 |
| 通道让行 | 狭窄通道先让堵路者侧移，后续观测再通过；不穿当前占用格、不互换、不抢同一目的格 |
| 无空位 | 无合法侧移位置时等待，不输出非法动作 |
| 分区值守 | 两工人收敛到上/下内侧岗位；岗位站反时多轮让行恢复，无动作拒绝 |
| 城墙掩护 | 左右镜像、活墙遮挡、毁墙缺口、内侧敌人、多敌人分别评估、仅擦角不计掩护通过 |
| 维修岗位 | 近敌时仍在墙后修危墙；入口静态封堵不再触发远距离逃离；夜间毁墙保留双维修，白天恢复补建 |
| 动态备货 | 第3/4/6/10天默认5/8/14/26包；昨日确认消耗17时目标至少19；失败反馈不计数，黎明反馈正确归昨日 |
| 配置 | 每日增长0可关闭，负数、过大值、bool和小数拒绝 |
| 既有策略 | 三炮开局、U墙/P站位、冷却、集中升级、基地不升级、批量购买、任务模块全部回归通过 |
| 合成观测压力 | 80份，0失败；中位21.242ms，最大817.645ms |
| 真实进程HTTP | POST原样例返回200、3条动作、46.655ms；健康检查和0.0.0.0监听通过 |
| 离线回放 | 原始request.txt成功输出标准三字段响应 |
| 安装包 | 0.3.7 wheel成功构建；22个Python模块与当前源码逐字节相同 |

首批6项新增测试在实现前为3失败、2错误，复现缺少独立任务/协调器、忽略墙掩护、固定5包及没有分区岗位等问题。让路夹具保留官方八方向移动：侧移口放在等待者不能直接绕入、堵路者可以进入的位置，避免把合法对角绕行误判为卡位。

原测试仅将“第四天已有1包补4包”的预期更新为新目标8包、补7包；其他原有回归保留。没有放宽碰撞、资源、角色权限或危险输入的校验。

## 验证边界

让行和岗位测试使用人工构造地图及逐轮位置反馈，证明这些场景能合法推进；不是任意地图无死锁的证明。侧移空间不存在、动态敌人封路或长期缺报仍可能让角色等待。

墙掩护是根据用户实战反馈采用的策略几何判断，未改写官方机器人伤害/弹道规则；不预测墙在当前回合末倒塌后的未来安全性。无法到达维修区时保持任务而不远逃，不能保证暴露角色不会死亡。修复包需求增加仍受金币、容量与往返时间限制。

本次没有运行官方完整双队对局、官方LLM/沙盒或Linux比赛入口，不据这些本地结果宣称实战胜率或存活时间提升。
